# Itinerario Artistico

Web app/PWA per creare e presentare itinerari artistici con mappa, tappe, immagini e percorsi pedonali.

## Funzioni
- più itinerari salvati nel browser;
- ricerca di città e punti d'interesse;
- mappa a sinistra e scheda tipo slide a destra;
- percorso pedonale 1→2, 2→3, ecc.;
- distanza e tempo di ogni tratto e totale;
- immagini personalizzabili per ogni tappa;
- modalità Presentazione;
- esportazione/importazione dei progetti;
- installazione come PWA sui browser compatibili.

La cartografia usa dati OpenStreetMap, visualizzati tramite CARTO. Il routing pedonale usa un endpoint pubblico Valhalla.
